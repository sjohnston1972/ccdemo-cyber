--------------------------------------------------------------------------------
[LOW RISK] Finding #1: CDP Enabled and Broadcasting
--------------------------------------------------------------------------------

Risk Level: LOW

Description:
Cisco Discovery Protocol (CDP) broadcasts device information that could aid
reconnaissance. CDP packets contain valuable information about the device
including hostname, platform, IOS version, and interface details.

Evidence:
The following CDP neighbors were detected, indicating CDP is active:
  - Device: switch2.example.com (Switch, IOS Platform) via GigabitEthernet0/1
  - Device: router1.example.com (Router, IOS Platform) via GigabitEthernet0/1

Total CDP entries: 2

Impact:
An attacker on the same network segment could use CDP information to:
- Map network topology
- Identify device models and software versions
- Discover management interfaces
- Plan targeted attacks based on platform information

Recommendation:
Consider disabling CDP on external-facing interfaces or globally if not needed:
  Interface level:
    interface <interface-id>
    no cdp enable

  Global level (if CDP not needed):
    no cdp run

Note: If CDP is required for network management tools, ensure it's only enabled
on trusted internal interfaces.

Remediation Priority: LOW
Estimated Effort: 5 minutes
